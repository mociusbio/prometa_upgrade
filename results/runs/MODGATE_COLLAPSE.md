# mod_gate 塌缩的完整记录（阴性结果的原始证据）

> 数据源：`clsdual_modgate/` 与 `clsca_modgate/` 各 3 seeds 的运行 JSON。
> 每个 JSON 的 `per_task_details[i].mod_gate_w` = 该疾病在 support 上 inner-adapt 10 步后
> 学到的融合权重 `[w_prot, w_meta]`（softmax 输出，和为 1）。
> 复算脚本见文末。

## 结论：每个 seed 塌缩为一个与疾病无关的常数

| 42 | 0.5010 | 0.4990 | 0.0001 | 0.4989 | 0.4993 | 0.0004 |

## 两个数字分别是什么意思

- **~0.54（0.499~0.565）是"塌到的位置"**：代谢支平均分到的融合权重。
  所有 seed 都塌在"约等于一人一半"附近，且不同 seed 塌的位置不同
  （0.499 / 0.514 / 0.518 / 0.534 / 0.534 / 0.565）——如果这是学出来的"正确答案"，
  6 次独立运行应该收敛到同一个值；位置随 seed 漂移说明它由优化噪声决定。
- **0.0001 是"塌得多死"的统计量**：91 个疾病的 w_meta 标准差。
  若门控真的按疾病分工（设计初衷），应该有的病 w_meta→0（主要靠蛋白）、
  有的病 w_meta→1（主要靠代谢），std 应在 0.1~0.3 量级。
  实测 std ≈ 0.0001、91 病最大最小差 < 0.0014 —— **没有任何逐病分化**。

## 机制解释

inner loop 从 32 个 support 样本（16 病例 + 16 对照）获得的分给 mod_gate 的梯度信号趋零：
门控对 loss 的敏感度太低，10 步适应内每个疾病都收敛到同一点；
门控退化为全局特征缩放（分类器权重可吸收），因此性能 ≈ 基线（0.7079 / 0.7084）。

这一发现与手动规则测试（融合增益与单组学强度相关 ≈ 0）互为印证：
**在 64 样本规模的 support 上，"哪个组学对这个疾病更重要"的信号不可识别**。

## 复算

```python
import json, numpy as np
for exp in ['clsdual_modgate', 'clsca_modgate']:
    for f in sorted(__import__('glob').glob(f'results/runs/{exp}/seed*.json')):
        d = json.load(open(f))
        wm = np.array([t['mod_gate_w'][1] for t in d['per_task_details']])
        print(d['config']['seed'], wm.mean(), wm.std())
```
